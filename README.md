# 🏠 WorkFromHome Equipment Store

A responsive e-commerce website that helps remote workers find essential work-from-home equipment in one place.

## 🎯 Problem

Remote workers need equipment such as laptops, headsets, monitors, internet accessories and backup power.

## 💡 Solution

An online store where users can:

* Browse products
* Search and filter products
* View product details
* Add items to cart
* Update quantities
* Calculate totals
* Complete a checkout form

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎯 Goal

To demonstrate my ability to build a functional, responsive e-commerce website using core web development technologies.
